# Events

`Makinuk\ICalendar\Component\Event` represents a `VEVENT` (RFC 5545 §3.6.1).

## Creating events

```php
use Makinuk\ICalendar\Component\Event;

// Shortcut: summary, start and optional end
$event = Event::create('Sprint review', '2026-10-01 14:00', '2026-10-01 15:00');

// Or step by step, with your own UID
$event = (new Event('booking-42@example.com'))
    ->setSummary('Sprint review')
    ->setStart('2026-10-01 14:00')
    ->setEnd('2026-10-01 15:00');
```

**UID.** When omitted, a random UUID is generated. If you publish the same event more than once
(a feed, an updated invitation), derive the UID from your own primary key so that calendar clients
recognise it as the same event instead of creating a duplicate.

## End or duration

An event has either an end or a duration. Setting one clears the other.

```php
use Makinuk\ICalendar\Value\Duration;

$event->setEnd('2026-10-01 15:00');
$event->setDuration(Duration::of(hours: 1, minutes: 30));
$event->setDuration(new DateInterval('PT90M'));
```

## All-day and multi-day events

```php
// A single day: no end needed
(new Event())->setAllDay()->setStart('2026-10-29')->setSummary('Republic Day');

// 10–12 November: the end date is exclusive, so it is the day after the last day
(new Event())->setAllDay()->setStart('2026-11-10')->setEnd('2026-11-13')->setSummary('Conference');
```

All-day dates are written as `DATE` values (`DTSTART;VALUE=DATE:20261029`) in the time zone of the
date you pass, so they never move to another day.

## Properties

| Method | Property | Notes |
|---|---|---|
| `setUid(string)` | `UID` | generated by default |
| `setTimestamp(date)` | `DTSTAMP` | defaults to the creation time of the object |
| `setCreated(date)` / `setLastModified(date)` | `CREATED` / `LAST-MODIFIED` | |
| `setStart(date)` / `setEnd(date)` / `setDuration(duration)` | `DTSTART` / `DTEND` / `DURATION` | start is required |
| `setAllDay(bool)` | `VALUE=DATE` | |
| `setSummary(string)` | `SUMMARY` | the title |
| `setDescription(string)` | `DESCRIPTION` | line breaks are kept |
| `setLocation(string)` | `LOCATION` | an address, a room or a meeting link |
| `setGeo(lat, lon)` | `GEO` | decimal degrees |
| `setUrl(string)` | `URL` | |
| `setOrganizer(Organizer\|email, name)` | `ORGANIZER` | |
| `addAttendee(Attendee\|email, name)` | `ATTENDEE` | see [invitations](invitations.md) |
| `addCategory(string ...)` | `CATEGORIES` | |
| `setClassification(Classification)` | `CLASS` | `Public`, `Private`, `Confidential` |
| `setPriority(int)` | `PRIORITY` | 1 (highest) to 9 (lowest), 0 undefined |
| `setSequence(int)` | `SEQUENCE` | revision number of an invitation |
| `setStatus(EventStatus)` | `STATUS` | `Tentative`, `Confirmed`, `Cancelled` |
| `setTransparency(Transparency)` | `TRANSP` | `Transparent` does not block time on free/busy |
| `setColor(string)` | `COLOR` | a CSS3 color name (RFC 7986) |
| `setRecurrenceRule(RecurrenceRule)` | `RRULE` | see [recurrence](recurrence.md) |

| `addAttachment(uri, mimeType)` | `ATTACH` | |
| `addAlarm(Alarm)` | `VALARM` | see [alarms](alarms.md) |
| `addProperty(Property)` | anything | see [extending](extending.md) |

Every setter returns the event itself, so calls can be chained. Setting a value to `null` removes it.

## Validation

`render()` throws a `ValidationException` when:

- the event has no start
- the end is before the start (for all-day events: not after the start date)
- the duration is negative
- the event has a recurrence rule or exception dates but no start
